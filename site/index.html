brolog is a single executable that opens a live system dashboard in your browser. It showcases brobridge: one WebSocket, independent binary streams, backpressure and reconnects. Loopback is not a security boundary in a browser, because other pages can reach local listeners. brobridge adds a one-time launch token, a strict session cookie and a request fence so only your admitted tab can connect. 

curl -fsSL https://praveenvijayan.github.io/brolog/install.sh | sh

macOS and Linux. Installs to ~/.local/bin and launches the app. Downloads become available after the first release is published.

macOS · Apple siliconmacOS · IntelLinux · x64Linux · ARM64Windows · x64

The Bun runtime is embedded. Current builds are approximately 62–86 MiB, depending on platform. macOS may block unsigned downloads: allow the app in Privacy & Security or use the curl installer. Windows SmartScreen may show a one-time warning. No Bun installation needed.
